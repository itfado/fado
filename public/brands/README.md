# Logo các thương hiệu

Thả logo từng brand vào đây. Đặt tên theo `slug` trong `src/data/brands.ts` để tự map:

| File cần đặt | Brand |
|---|---|
| `fado-vn.svg` | FADO.VN |
| `proship.svg` | Proship |
| `ratraco-solutions.svg` | Ratraco Solutions |
| `fado-solutions.svg` | FADO Solutions |
| `woka.svg` | Woka |
| `fado-agri.svg` | FADO Agri |
| `goprint.svg` | GoPrint |
| `fanaro-solutions.svg` | Fanaro Solutions |
| `baby-train.svg` | Baby Train |
| `star-kidz.svg` | Star Kidz |
| `nanny-annie.svg` | Nanny Annie |
| `ch-smith-marine.svg` | C.H. Smith Marine |
| `kayaks2fish.svg` | Kayaks2Fish |

**Ưu tiên SVG** (sắc nét mọi kích thước, đổi màu được theo theme). Nếu chỉ có PNG thì dùng nền trong suốt, tối thiểu 240px chiều cao.
